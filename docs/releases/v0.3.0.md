# PrePro v0.3.0: the review app

v0.3 adds a review app. You open a shoot folder in your browser and go from raw footage to an exported cut,
changing anything you disagree with along the way. It runs on your computer only.

```bash
prepro ui        # http://127.0.0.1:8765
```

## The five steps
1. **Footage.** Analyse the folder locally and see every clip with its problems (shaky, blurry, dark,
   duplicate). Search what was said or shown, e.g. "kachori" or "beach".
2. **Brief.** Optional. Write it like a note to your editor, in English or Hinglish, and see at once which
   rules PrePro understood and whether it found the moments you mean.
3. **Directions.** You get 2–4 ways to cut the footage. Each comes with hook options shown as thumbnails, a
   plain-words reason for each, an outline, and what to shoot next time.
4. **Review.**
   - **Player and timeline.** A player and timeline lanes (text, overlay, picture, voice, music, SFX), with a
     dot for every decision and a retention heat strip that shows where viewers are likely to swipe away.
   - **Every decision has a ✓/✕.** Its reason is shown next to it. Rejecting recompiles the cut in about a
     second, and rejected items stay listed so you can bring them back.
   - **Notes at the playhead** become edits, for example "remove zoom", "big text: ₹500 only", "meme here",
     "whoosh", "faster", "cut this", "change song", "music quieter" or "another hook".
     - A note that conflicts with your brief says so.
     - A note PrePro can't turn into an edit is reported, not guessed.
     - Delete a note to undo it.
   - **Hook picker, knobs, scorecard.** The knobs (pace, effects, captions, humour, length) rebuild the cut
     and keep your choices. The scorecard sits alongside the brief checklist, the checks, the music plan and
     the paper edit.
5. **Export.** Premiere/Resolve, Kdenlive, Shotcut, phone apps, captions, caption overlay, and the editor
   brief, with links to the files.

## Safety
- The server listens on 127.0.0.1 only.
- Every API call needs a token created at launch, and foreign Host headers are rejected (DNS rebinding).
- Files are served only from shoot folders you opened; path traversal is tested.
- There are no CORS headers.

## Fixed
- Under concurrent requests the project cache could silently move to another folder, which showed up as
  missing thumbnails.

## Verified here
- 59 engine/server tests are green.
- A real Chromium run of the whole flow (open → analyse → brief → directions → build → reject → note →
  export) had no HTTP errors and no horizontal scroll at phone width (390 px).

## Not yet
- No desktop installer yet (v0.4). For now run `prepro ui` from a Python install.
- Whisper is not testable in the build machine. Live AI connectors other than Claude Code were tested against
  stubs only.
