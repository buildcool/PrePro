# PrePro v0.4.0: the desktop app

PrePro now installs like any other app on **Linux** (AppImage or .deb) and **Windows** (installer). You don't
need Python or a terminal: open PrePro, click **Browse…**, pick your shoot folder, and go from footage to an
exported cut.

## Downloads (attached to this release)
| System | File |
|---|---|
| Linux, any distro | `PrePro-0.4.0-linux-x86_64.AppImage` (468 MB): make it executable, then double-click |
| Ubuntu / Debian | `PrePro-0.4.0-linux-amd64.deb`: `sudo apt install ./PrePro-0.4.0-linux-amd64.deb` |
| Windows 10/11 | `PrePro-0.4.0-win-x64.exe` |

## How it works
- The app starts PrePro's engine on your own computer (127.0.0.1) and shows the review app in a locked-down
  window:
  - no Node.js in the page
  - only two native actions: pick a folder, show a file in its folder
  - links to other sites open in your browser
- Your footage is never uploaded. If you switch on an AI brain, only text (and optionally small thumbnails)
  is sent, and you can see exactly what in `.prepro/sent/`.
- ffmpeg ships with the installer, along with its licence. Speech-recognition models download the first time
  you analyse speech.

## Also new: Shorts from long talks
If your shoot has long talking footage (a podcast, an interview, a long vlog), open the **Directions** step and
click **Find Shorts**. PrePro looks for moments that work on their own:
- a first line with a number, a question or a strong claim;
- one idea, ending on its lesson or punchline;
- no two Shorts covering the same part.

Each one becomes a vertical Short with bold captions that you review, change and export like any other cut. You
can also run `prepro shorts <folder>` from the command line.

## Fixed
- Kdenlive export works in the installed app, and vertical cuts open as vertical projects in Kdenlive.
- A duplicate OpenCV package (pulled in by an unused dependency) was removed.

## Verified here
- The frozen engine ran the whole flow over its API: analyse → directions → build with preview render →
  export to every format. The brief was 100 % met.
- The Electron app started the frozen engine under a virtual display:
  - the page is local-only, with no Node.js and the bridge present
  - a shoot opened
  - quitting stopped the engine
- The Linux AppImage and .deb were built here, and the extracted AppImage was launched: the bundled 0.4.0 engine
  started and the bridge was present.
- Without transcript files, the frozen engine fell back to the offline PocketSphinx recogniser. Whisper models
  can't be downloaded in the build machine; on your computer they download on first use.

## Known limits
- **The installer is large.** Before the latest trimming the Linux .deb was 310 MB and the AppImage 440 MB,
  because local speech recognition, OpenCV and audio analysis ship inside it. The AppImage also bundles ffmpeg.
- **The Windows installer is built in GitHub Actions** and was not run on a Windows machine before release.
  Please report anything odd.
- **The app isn't code-signed yet.** Windows SmartScreen will warn on first launch ("More info → Run anyway").
