# PrePro v0.9.1: the desktop app keeps itself up to date

Install this version by hand once; from here on PrePro can update itself.

## Updates, on your terms
A new **Updates** button in the top bar shows your version and what's new, and lets you pick how updates work:

- **Automatic**: checks once a day and downloads new versions in the background. It installs only when you click
  "Restart to update" or next close PrePro, so it never interrupts a render.
- **Tell me** (the default): checks once a day and tells you when a new version is out. Downloading and installing
  are your call.
- **Off**: PrePro never asks the internet about updates. "Check now" still works whenever you want.

Checking only asks GitHub which version is the latest, so GitHub sees your IP address and PrePro version. No footage,
file names or projects are sent.

The Windows installer and the Linux AppImage install updates themselves. The `.deb` package can't replace itself, so
it shows what's new and opens the download page.

Everything from v0.9.0 is included (photo reels, and the fix for the v0.8.0 start-up crash on Windows).
