# PrePro v0.1.0 — offline engine, end to end

The first usable release: a shoot folder goes in, a reasoned first cut comes out — with **no AI and no
upload** (Basic brain, everything local).

## What works
- **Analysis (local):** speech (sidecar subtitles → Whisper → PocketSphinx fallback) with fillers,
  false starts, retakes, greetings, emphasis; shots with blur/dark/shake/whip/duplicates, faces and moving
  subjects, action peaks; music BPM/beats/sections/mood; audio health; days and places (offline GPS
  reverse-geocoding); genre guesses.
- **Brief:** `brief.md` / `brief.yaml` / voice note / `HOOK_`/`MUST_`/`SKIP_` tags, English + Hinglish
  phrasing → hard rules + preferences, resolved to clips/lines; open questions when unclear.
- **Directions:** 2–4 cards (story vlog, travel film, hype reel, aesthetic, teaser, talking head, gaming,
  comedy, podcast) with 3 hook options, outline and coverage gaps.
- **Editing rules (playbooks):** cold-open hooks, per-place story parts with establishing shots and
  location cards, montages, soundtrack modes (bed/front/light), track ranking from *your* library (no
  invented songs), drop alignment / backtiming, ducking or muting under speech, motivated SFX, memes after
  punchlines (library or catalogue suggestions), real slow-mo on high-fps action, whips between B-roll,
  operator-style reframing for 9:16, word-pop captions with emphasis and phrase-aware breaks.
- **Quality gate:** EditLint (mid-word cuts, dead zones, over-stimulation, repeats, jump cuts, captions,
  bad shots, colour jumps, slow starts, duration, brief compliance, loudness/peaks/ducking) + rules critic.
- **Render:** preview/final MP4 at −14 LUFS / ≤ −1 dBTP, storyboard contact sheet for review.

## Try it
```bash
prepro demo travel_vlog --brief --out demo
prepro directions demo/travel_vlog_brief
prepro build demo/travel_vlog_brief
```

## Known limits
- Whisper models download from huggingface.co on first use (not testable in the build container).
- No AI connectors or NLE exports yet (v0.2), no UI yet (v0.3).
