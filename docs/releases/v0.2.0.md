# PrePro v0.2.0 — AI brain (any provider, subscription-first) + exports for every editor

v0.1 made a reasoned first cut offline. v0.2 lets an AI editor of your choice sharpen it, and hands the cut
to the editor you already use.

## AI brain (optional, local-first)
- **Use what you already pay for:** Claude Pro/Max through the official Claude Code CLI, ChatGPT Plus/Pro
  through the official Codex CLI, or a free Gemini key. API keys (Anthropic, OpenAI, Gemini, xAI Grok,
  OpenRouter) and local Ollama models also work. No AI at all still works (Basic brain).
- The AI improves the rules engine's draft in five passes: vision tags, directions + hooks + coverage gaps,
  story, polish (music/memes/SFX/text/VO), and a senior-editor **critic** whose safe fixes are applied.
  Every reply is schema-checked and every clip/line ID validated; on any failure the rules draft stays.
  Your brief always wins over the AI.
- **Privacy:** raw footage never leaves your computer. Levels: *local* (nothing sent), *text*
  (transcript + clip facts), *thumbs* (+ small frames, optional face blur). File names and GPS are never
  sent. A local log in `<shoot>/.prepro/sent/` shows exactly what went where.
- `prepro brains list | add | key | route | privacy | compare`.

## Exports
| For | You get |
|---|---|
| Premiere Pro, DaVinci Resolve | FCP7 XML: bins (A-roll, B-roll by day · place, rejects, music, SFX, memes), punch-ins, speed, ducking keyframes, dissolves, a marker with the reason for every decision |
| Kdenlive | `.otio` + `.kdenlive` |
| Shotcut | MLT XML (speed changes as timewarp; checked by rendering with `melt`) |
| InShot, VN, KineMaster, Instagram Edits | captioned MP4, clean MP4, no-music MP4 for trending audio, stems, SRT, cue sheet, beat plan |
| Any NLE | SRT/VTT, transparent ProRes 4444 caption overlay, the look's `.cube` LUT |
| A human editor | one HTML editor brief with storyboard, scorecard, brief checklist, every decision and what to shoot next |

```bash
prepro build my_shoot            # rules only, or --brain claude_code after `prepro brains add claude_code`
prepro export my_shoot --formats all
```

## Verified here
- FCP7 XML read back by OpenTimelineIO's FCP XML adapter: same clips, same cut points (±1 frame), all markers.
- OTIO round-trip duration within 2 frames; MLT rendered headless with `melt` to the timeline's length.
- Phone pack: 1080×1920 H.264 4:2:0, constant 30 fps, AAC 48 kHz, −14 ±1 LUFS (ffmpeg `ebur128`).
- Live AI build with Claude Code on a Claude plan (4 calls, text-only privacy) — see `docs/QA.md`.

## Not verified here (please try)
- Opening the XML in Premiere Pro and Resolve, and the `.kdenlive`/`.mlt` in Kdenlive/Shotcut (no GUI
  editors in the build machine). Position values for punch-ins/reframes use the Premiere convention.
- Whisper speech recognition (its models can't be downloaded in the build machine; PocketSphinx and
  subtitle sidecars were used instead). Codex, Gemini, OpenAI, xAI, OpenRouter and Ollama connectors were
  tested against stubs, not live.
