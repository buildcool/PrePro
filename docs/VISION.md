# Vision: an autonomous pre-editor

PrePro is a **fully autonomous pre-editor**. A creator points it at a shoot folder and gets **about 90 % of the edit
done**: a finished, reasoned, export-ready first cut. They will still edit (in the review app or their own editor),
but they never have to *drive* the edit to get there.

What that means in practice:
- **One action to a finished cut.** Open a shoot → analyse → pick the best direction → edit → render → export, end to
  end, with live progress. Brief, direction, style and music choices are refinements, never gates.
- **Think like a professional editor, not like a form.** The engine makes the calls an editor would (hook, story,
  pacing, music, captions, text, framing) and explains each one.
- **Every decision is the creator's to undo.** Each edit decision carries a reason and can be rejected in the review
  app; a rejection never breaks the rest of the cut.
- **Desktop-quality experience.** A real settings window, light and dark themes, progress that always shows what is
  happening, and AI accounts that connect in a click.
- **Private by default.** Footage never leaves the PC; only text (and, if allowed, small thumbnails) goes to an AI.

Judge every feature by one question: *does this get the creator closer to a finished cut without asking them?*
